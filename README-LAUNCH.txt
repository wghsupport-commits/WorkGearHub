WORKGEAR HUB LAUNCH PACKAGE

This package reuses your existing index.html and adds basic Progressive Web App (PWA) files.

Included:
- index.html: original prototype with PWA setup added
- manifest.webmanifest: install metadata
- sw.js: basic cache/offline fallback
- icons/: 192px and 512px app icons

PUBLISH FREE WITH GITHUB PAGES
1. Sign in to GitHub and create a public repository, e.g. workgear-hub.
2. Upload all files and folders from this package to the repository root (not just the ZIP).
3. Open repository Settings > Pages.
4. Choose Deploy from a branch, select main and /(root), then save.
5. Wait for GitHub Pages to provide the public URL and test it over HTTPS.
6. Open the URL in Chrome on Android; use the browser menu and choose Install app or Add to Home screen when offered.

IMPORTANT LIMITATIONS
- Featured products are placeholders; affiliate links and real prices are not included.
- Inquiry forms prepare text locally; they do not send submissions to a server.
- No orders, seller accounts, payment processing, or marketplace commissions are implemented.
- This is a PWA starting point, not a Google Play Store release.
- A custom domain is optional and usually costs money.
- Google Play publishing requires a Play Console developer account. Google currently lists a one-time US$25 registration fee, and new personal accounts may have testing/device verification requirements.
